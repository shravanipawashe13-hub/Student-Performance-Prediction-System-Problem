# 🎓 Student Performance Prediction & Academic Analytics System
### BCA Final Year / Major Academic Project

An end-to-end Data Science and Business Intelligence solution designed to predict student examination outcomes, detect at-risk students early, and provide actionable academic interventions using **Python, Pandas, Seaborn, Decision Trees, Streamlit, and Microsoft Power BI**.

---

## 🌟 Key Features

1. **🔐 Secure Role-Based Access Control (RBAC) & Login Portal**:
   - **👑 Admin Role (`admin / admin123`)**: Full system access + **Admin Exclusive Ability** to create and manage Teacher accounts.
   - **👩‍🏫 Teacher Role (`teacher / teacher123`)**: Evaluate student performance, insert/delete SQL database records, manage reminders, and generate student report cards.
   - **🎓 Student Role (`student / student123`)**: View personal official Academic Report Card, attendance standing, and progression trajectory (locked to student's own record).
   - 1-Click Quick Demo Login buttons for easy viva presentations.

2. **📑 Official Student Academic Report Cards**:
   - University-formatted printable report cards complete with institution headers, continuous assessment table, predicted marks, GPA/letter grade, and faculty remarks.
   - 1-Click **Download Printable HTML / PDF** button.

3. **📊 Exploratory Data Analysis (Seaborn)**:
   - High-resolution statistical plots exploring attendance, study hours, internal exams, sleep patterns, and parental education.
   - Correlation heatmaps, distribution curves, and non-linear regression trends.

2. **🌳 Machine Learning with Decision Trees**:
   - **Decision Tree Classifier**: Classifies students into 4 performance tiers (*Distinction, Merit, Pass, At-Risk*).
   - **Decision Tree Regressor**: Predicts continuous numerical percentage scores (0–100).
   - Pre-pruning to avoid overfitting (`max_depth=5`, `min_samples_leaf=5`).
   - Exported visual Decision Tree flow diagram (`decision_tree_structure.png`).

3. **🗓️ Periodic Progression Tracking (Monthly & Quarterly Evaluations)**:
   - Cadence selector for **Monthly** (Months 1–6) or **Quarterly** (Q1–Q4) cycles.
   - Interactive Plotly line charts displaying score and attendance trajectories over time.
   - Net performance delta metrics (improving 📈 vs declining 📉 trajectories).
   - Form to log new periodic progress entries on-the-fly.

4. **📜 Past Added Data & Student History Log**:
   - Persistent database log in `data/student_history.csv`.
   - Real-time KPI cards (Total Evaluated, Distinction, Merit, Pass, At-Risk).
   - Filter by student name, ID, or tier with one-click CSV export.

5. **⏰ Academic Reminders & Early-Warning Alert Center**:
   - Color-coded priority alerts (🔴 High, 🟡 Medium, 🟢 Low).
   - Schedule reminders for attendance deficits, remedial classes, or evaluation deadlines.
   - ⚡ Auto-Scan button that scans the database and generates alerts for struggling students.

6. **💻 Interactive Streamlit Web Application**:
   - **Live Predictor**: Slide attendance, marks, and study hours for instant prediction.
   - **Prescriptive AI Advisory**: Dynamic recommendations tailored to individual student gaps.
   - **EDA Visual Gallery**: Browse all statistical Seaborn charts with insights.
   - **Bulk Batch Prediction**: Upload class-wide CSVs and download results.

4. **📈 Microsoft Power BI Project Kit**:
   - Clean, enriched dataset (`student_performance_powerbi.csv`).
   - 15+ ready DAX measures in `powerbi/dax_measures.txt`.
   - Custom modern theme JSON in `powerbi/powerbi_theme.json`.
   - Step-by-step 3-page dashboard creation manual in `powerbi/POWERBI_DASHBOARD_GUIDE.md`.

5. **📚 Complete Academic Submission Package**:
   - `PROJECT_REPORT.md`: Comprehensive academic project report (SRS, Architecture, DFD, Math).
   - `VIVA_QUESTIONS.md`: 25+ essential viva-voce questions and expert answers.
   - `student_performance_notebook.ipynb`: Jupyter notebook for lab presentation.

## 🚀 How to Run on ANY PC (Zero Configuration)

This project has been engineered to run seamlessly on **any computer** (Windows, macOS, Linux) without manual configuration:

### 🌟 Option 1: 1-Click Launch (Windows)
Simply double-click:
```
run_app.bat
```
*(or right-click `run_app.ps1` and select "Run with PowerShell")*

---

### 🌟 Option 2: Universal Terminal Command (Windows, macOS, Linux)
Open your terminal in the project folder and run:
```bash
python run.py
```
> **What `run.py` automatically does for you:**
> 1. ✅ **Detects your Python version** (compatible with Python 3.9, 3.10, 3.11, 3.12, 3.13).
> 2. ✅ **Auto-checks and installs dependencies** from `requirements.txt` via `pip`.
> 3. ✅ **Auto-generates datasets and trains ML models** if starting on a clean machine.
> 4. ✅ **Initializes SQLite database** and role-based login accounts.
> 5. ✅ **Launches the Streamlit Web Application** at `http://localhost:8501`.

---

### 🌟 Option 3: Manual Execution (Step-by-Step)
If you prefer running commands manually:
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Launch Streamlit Web Application
streamlit run app.py
```
